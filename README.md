## What is this project?

Imagine several computers keeping the same notebook of transactions. What happens if a message arrives late, or two computers add different pages at nearly the same time? **Consensus Lab** will be an interactive educational simulator for exploring how blockchain computers follow shared rules and eventually agree on a valid history.

This is a **planned student project**, not a finished simulator. It uses pretend transactions and no real cryptocurrency.

## Research question

**How do network delays affect temporary forks and agreement in a simplified Proof-of-Work blockchain network?**

If time permits, an extension will explore invalid messages or dishonest participants. The simulator will be an educational simplification, not a complete Bitcoin implementation.

## Planned features

- Simulate multiple nodes (computers) communicating with one another
- Create and validate pretend transactions and blocks
- Simulate Proof-of-Work mining and competing valid branches
- Change network delay and observe temporary forks
- Visualize agreement and collect experimental results

## Planned technology

Python, Streamlit, SimPy, pandas, Plotly, pytest. The final stack may change as the project develops.
